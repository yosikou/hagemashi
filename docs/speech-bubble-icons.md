# 吹き出しアイコン

main 8e2963aから独立分岐。ランチャーは深い緑の背景＋クリーム色の吹き出し＋笑顔。通知は同じ吹き出しの輪郭を白一色のシルエットにする。通知アイコンに色・細い線・文字を入れず、小さいステータスバーでも判別する。元のハート形を置換する。

API 26以上のadaptive iconを用い、前景を安全領域内へ収める。roundIconも同じadaptive icon。API 33以上のテーマ付きアイコン向けに同じ形のmonochromeを用意する。診断版と通常版の両方へ適用し、applicationId・署名・回答ID・通知タップ処理は変更しない。通知小アイコンは既存の通知と期限案内の両方に適用される。

ソース確認：ランチャー前景・monochrome・通知ベクターの吹き出しpath一致、通知は不透明白のpath1個、adaptive iconとManifest参照を確認。デザインプレビューは端末描画ではない。

Android試験：既存APKへ上書きし、ホーム／アプリ一覧で色付きの吹き出しへ変わること、円／角丸のランチャーマスクで欠けないこと、テーマ付きアイコンも判別できることを確認する。予約通知または診断版の既存「通知を試す」で通知欄・小アイコン・ロック画面を確認する。朝夜通知から対応する全文と当時の短文タイトルを開けることを確認する。ランチャーが古い絵をキャッシュしている場合は別の画面へ移動して再表示し、データ消去やアンインストールは不要。今回の実機の見え方は未確認。権限・依存の追加なし。
