# 通常版UIと手動送信確認

main 8e2963aから独立して分岐。BuildConfig.BUILD_TYPEがdiagnosticのときだけ原因調査の画面・ビルド番号・DNS比較・固定ダミー生成・保存済み回答の検証通知を表示する。通常debug APKも通常版としてこれらを隠す。通常版は保存済みテスト回答の予約を実行せず、自動生成をオフにしても旧試験通知を配信しない。既存の設定・認証・回答を消さず、自動生成と期限案内の制御は維持する。公開時のSIWC用途条件確認は別の残課題で、製品用の見た目を正式適用承認と扱わない。

通常版のエラーは通信確認・再接続・モデル再選択・利用上限確認・端末保存状態の確認など、ユーザーが対処できる案内とする。診断版には従来の安全な診断と固定データ生成を残す。復元された診断画面のrouteも通常版では設定へ戻す。

送信確認の先頭はChatGPTプランへの送信、使用モデル・人格、送る項目、各項目の最新値と対象期間、目標を表示する。「送信データをすべて見る」で全測定表・目標／期限・人格プロンプト・補足・生成方針を展開する。全値は確認時点のReviewedGenerationに固定し、「生成する」は同じinput/instructions/modelを送る。取得後の新しい記録・設定を混ぜず、過去の回答は送らない。表示用の同日同値まとめと分までの現地日時は維持し、元の送信データをまとめない。画面を離れると確認内容を破棄する既存の安全性を維持する。

Android試験：通常APKと診断APKをそれぞれ既存の同じapplicationIdへ上書きし、通常版のホーム・設定・詳細に診断・ダミー・検証通知・ビルド番号がないこと、診断版には残ることを確認する。通常版から接続／解除、健康データ確認、手動確認→概要→全データ展開／折りたたみ→生成ができ、履歴へ保存されることを確認する。確認後に新しい測定が届いても取得済みの内容を送る。朝夜通知から対応する全文が開き、短文と見出しが一致し、通常の手動生成では通知しないことを確認する。APKのコンパイルはAndroid UIテスト実行ではなく、今回の実機動作は未確認。新しい権限・依存・データ保存先の変更なし。
